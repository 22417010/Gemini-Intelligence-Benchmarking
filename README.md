
# 🧪 Gemini Intelligence Benchmarking: RAG vs. Long Context

## 🌟 Overview
This project is an AI engineering experiment to compare two dominant strategies in Large Language Models (LLMs):
1. **Retrieval-Augmented Generation (RAG):** Efficient, cost-effective, and fast.
2. **Long Context Window:** Holistic understanding by processing entire documents.

## 🛠️ Tech Stack
- **Engine:** Python 3.10
- **Vector DB:** FAISS (Facebook AI Similarity Search)
- **Models:** Gemini 1.5 Flash & NVIDIA Nemotron-3 (via OpenRouter)
- **Embeddings:** Sentence-Transformers (Local)

## 📐 System Architecture
The system extracts text from PDFs, creates a semantic index, and performs a dual-path benchmarking to measure response time and accuracy.



## 🚀 Quick Start
1. Open the notebook in Google Colab.
2. Insert your OpenRouter API Key.
3. Upload a PDF and start benchmarking!
